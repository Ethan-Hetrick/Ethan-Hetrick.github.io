## Selected Projects

- **Microbial Eukaryote Comparative Genomics** — Constructed a DuckDB database of ~100 million pairwise genome comparisons (~10,000 genomes) across dozens of columns; analyzed thousands of genomes spanning ~80 genera and over 1,000 species using multinomial logistic regression, graph clustering, and precision–recall/F1 evaluation. Co-first author (manuscript in review).
- **nf-core contributor** — Authored and merged an average nucleotide identity module into the upstream nf-core repository, conforming to current nf-core guidelines with an accompanying nf-test and passing required CI/CD checks. https://github.com/nf-core/modules
- **FoodNet Trends** — Implemented Bayesian negative-binomial spline regression in R (brms/rstan) with population offsets, posterior incidence estimates, and credible intervals; built configurable MCMC workflows supporting surveillance across 10 U.S. sites.
- **fasterANI** — Multithreaded, memory-safe ANI implementation in Rust using minimizer-based sketches, cached on-disk indexes, memory mapping, and bounded parallelism. Improved on the gold-standard ANI tool's runtime by roughly 5× with substantially lower peak memory, while maintaining near-perfect correlation with FastANI.
- **ARX Threat Report** — Reimplemented national antimicrobial-resistance burden aggregation in Python (vectorized NumPy, FFT convolution) across ~20 pathogens, reducing a non-completing workflow to under a minute; supported division-level funding decisions.
- **neissflow** — Portable production workflow for *Neisseria gonorrhoeae* genomic epidemiology, adopted by state and international partners including lower-resource environments.
- **RADish** — End-to-end ddRAD-seq workflow for mosquito insecticide-resistance surveillance; SNP comparisons, Fisher's exact tests, PCA, and biological annotation. Processes up to 96 samples in a few hours on CDC HPC.
- **PolkaPox** — Co-author of a Nextflow workflow for filtering, trimming, QC, reference-based analysis, and de novo assembly of Illumina short reads from orthopoxviruses; de novo assembly optimized for the linear orthopoxvirus genome architecture. https://github.com/CDCgov/polkapox
- **wf-assembly-snps** — Modular bacterial surveillance workflow producing core-genome alignments, SNP distances, recombination-aware phylogenies, and annotated visualizations with containerized HPC execution.
- **seqlint** — Command-line linter in Rust for bioinformatics sequence files, running pre-flight integrity checks, format validation, and heuristic analysis (magic-byte and compression detection, encoding/byte-level scanning, IUPAC and format-specific checks for FASTA/FASTQ) to catch malformed inputs before pipeline execution and improve reproducibility. https://github.com/Ethan-Hetrick/seqlint
- **LEGION** (Legionella Genomic Investigation and Outbreak analysis in Nextflow) — Nextflow pipeline for species identification, sequence-based typing, genome assembly, and phylogenetic analysis of *Legionella* isolates.
- **Arbovirus Metagenomics** — Pilot study evaluating metagenomic methods for detection and assembly of arboviruses across a variety of hosts, sample types, and sequencing protocols.
- **SPN Typing Workflow** — Converted a *Streptococcus pneumoniae* typing workflow to Nextflow, integrating preprocessing, subtyping, AMR typing, and automated reporting into a single end-to-end pipeline.
